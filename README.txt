二、这一版改了什么
----------------------------------------------------------------------
1）修「一进 App 上下两条大黑边」（这是根因，不是补丁）

   病因：TabView 和播放页都是按「安全区」布局的。它们里面的背景虽然用
   ignoresSafeArea() 能画到状态栏和底部横条上，但只要这条链路上挂了
   .clipShape(RoundedRectangle(cornerRadius: ...))，裁剪边就是「安全区矩形」，
   圆角是 0 也照样硬切一刀，把铺出去的那部分削平，露出的就是底下的深色层。
   4.6 加「卡片堆叠」效果时给根 TabView 套了这个裁剪，黑边就是从那一版开始的；
   4.8 只调了播放页的修饰符顺序、裁剪还挂着，所以依旧。

   改法：新增 CardClip 修饰符 —— 圆角为 0 时什么都不做，只有真要圆角才裁。
   · 根 TabView：收起状态完全不裁（scale 为 1，本来也不需要圆角）；
   · 播放页：只有往下拖动（dragOffset > 0.5）时才裁，静止时完全不裁。

2）底层配色跟着改
   根视图最底层原来是纯黑 Color.black.ignoresSafeArea()，现在：
   · 常态铺「页面同色」（AppBackground，即 systemGroupedBackground）；
   · 播放页打开时换成播放页自己的深灰 #212121（Color(white: 0.13)）。
   这样以后无论是哪一层没铺到安全区，露出来的都是同一个颜色，不可能再出现黑条；
   播放页四周的卡片底也不再是死黑，而是和页面一致的深灰。

3）版本号 4.8.0（build 9）→ 4.9.0（build 10）。

四、参数含义
----------------------------------------------------------------------
CardClip(active:radius:)
            active = false 或 radius ≈ 0 时不做任何裁剪（这是修黑边的开关）；
            active = true 时按 radius 裁圆角，样式 .continuous。
            用在两处：根 TabView 传 active: player.isOpen；
            播放页传 active: dragOffset > 0.5。

34 - 20 * player.pull
            底下那层卡片的圆角：播放页完全打开时 34pt，往下拉满（pull=1）时收到 14pt。
            只在 isOpen 为真时才真正生效。

0.94 + 0.06 * player.pull
            底下那层卡片的缩放：打开时 0.94，拉回时线性回到 1.00（即完全复原）。

0.42 * (1 - pull)
            底下那层卡片的压暗程度，跟着下拉进度变亮。

dragOffset > 0.5
            播放页的拖动位移阈值。0.5pt 以内视为「没在拖」，不裁剪；
            拖动后圆角为 min(34, dragOffset / 5)，位移 170pt 时到顶 34pt。

Color(white: 0.13)
            播放页底色 #212121 与「卡片堆叠的底」同色。
AppBackground
            页面底色 = UIColor.systemGroupedBackground（浅色浅灰、深色纯黑），全局无渐变。

MARKETING_VERSION / CURRENT_PROJECT_VERSION
            4.9.0 / 10，就是「关于本机」和 CI 产物里看到的版本。


五、怎么测试（重点看这几步）
----------------------------------------------------------------------
1. 冷启动 App：从桌面点开，等启动图消失后看第一屏（训练页）——
   状态栏那一块应该和导航栏连成一片，底部标签栏应该一直铺到屏幕最下沿，
   上下都没有黑条。音乐 / 成长 / 我的 三页各点一遍，同样不应有黑条。
2. 进播放页：音乐页点底部迷你条打开播放页 —— 一打开（还没拖动）就应该铺满整屏，
   状态栏区域是灰色液态玻璃、不是黑的；底部横条区域也是玻璃、不是黑的。
3. 往下划关闭播放页：往下拖时圆角出现、底下那层跟着放大变亮，
   松手回到列表；再进一次，确认没有残留黑边。
4. 旋转/切后台再回来：锁屏放歌 → 回 App，页面不应出现黑边。
5. 回归：专辑网格 → 专辑详情 → 播放，训练页记一组、休息计时，都正常。


六、已知限制
----------------------------------------------------------------------
· 整首播放要求歌已经在 Apple Music「资料库」里（自签包没有 MusicKit entitlement，
  不能直接拿云端曲库的完整版权限）。
· 系统音量仍是 16 级 —— MPVolumeView 内部 UISlider 的固有限制。
· 本次仍未在真机上验证（本机是 Windows，CI 只验证了编译通过、包结构和
  Info.plist 版本号），黑边是否彻底消失需要你在手机上确认第 1、2 步。
· 播放页往下拖到一半时，安全区那两条会被裁掉（拖动过程才出现，松手即恢复），
  不影响静止状态。
